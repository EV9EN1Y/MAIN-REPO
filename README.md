## 🎯 Что вы найдёте внутри

### 🔬 1. Полный аудит безопасности iOS-приложения **MeetWay**
MeetWay — это полноценная социальная сеть с мессенджером, 
которую я разработал с нуля. В этом разделе я провожу её всесторонний 
аудит как полноценный Security Engineer.

**Фокус аудита:**
- **Мобильная безопасность (OWASP MASVS):** Анализ хранения данных (Keychain, UserDefaults), защита бинарника, IPC.
- **Веб-безопасность (OWASP Top 10):**      Тестирование REST API на уязвимости (IDOR, SQLi, JWT-issues, SSRF).
- **Threat Modeling (STRIDE):**             Построение диаграмм угроз и анализ атакующей поверхности.
- **Облачная безопасность:**                Конфигурация и безопасность сервисов Yandex Cloud (YDB, YCF, Object Storage).

Каждый отчёт — это не просто описание бага, а исследование с PoC, разбором кода и рекомендациями по исправлению.
