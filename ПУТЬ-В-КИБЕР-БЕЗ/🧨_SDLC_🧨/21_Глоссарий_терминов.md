| Термин | Определение |
|--------|-------------|
| **AppSec** | Application Security – практика обеспечения безопасности приложений |
| **SDLC** | Software Development Life Cycle – жизненный цикл разработки ПО |
| **SSDLC** | Secure SDLC – безопасный жизненный цикл разработки |
| **Threat Modeling** | Моделирование угроз – выявление и анализ угроз для системы |
| **Shift Left** | Смещение безопасности на ранние этапы разработки |
| **SAST** | Static Application Security Testing – статический анализ кода |
| **DAST** | Dynamic Application Security Testing – динамическое тестирование |
| **IAST** | Interactive AST – интерактивное тестирование (агент в runtime) |
| **RASP** | Runtime Application Self-Protection – самозащита в рантайме |
| **SCA** | Software Composition Analysis – анализ зависимостей |
| **SBOM** | Software Bill of Materials – ведомость состава ПО |
| **CVE** | Common Vulnerabilities and Exposures – реестр уязвимостей |
| **CWE** | Common Weakness Enumeration – каталог типов слабостей |
| **CVSS** | Common Vulnerability Scoring System – оценка критичности (0-10) |
| **EPSS** | Exploit Prediction Scoring System – вероятность эксплуатации |
| **DFD** | Data Flow Diagram – диаграмма потоков данных |
| **STRIDE** | Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation |
| **DREAD** | Damage, Reproducibility, Exploitability, Affected, Discoverability |

| **OCTAVE** | Организационная оценка рисков (CERT/SEI) |
| **PASTA** | Process for Attack Simulation and Threat Analysis |
| **IDOR** | Insecure Direct Object Reference – доступ по ID без проверки прав |
| **XSS** | Cross-Site Scripting – межсайтовый скриптинг |
| **SSRF** | Server-Side Request Forgery – подделка серверных запросов |
| **SQLi** | SQL Injection – инъекция SQL |
| **OS Command Injection** | Инъекция команд ОС |
| **PoC** | Proof of Concept – доказательство эксплуатации |
| **Exploit** | Эксплойт – программа/метод использования уязвимости |
| **Zero-day** | Уязвимость без известного фикса |
| **Container Escape** | Побег из контейнера на хост |
| **SSL Pinning** | Привязка приложения к конкретному сертификату/ключу |
| **MFA** | Multi-Factor Authentication – многофакторная аутентификация |
| **SIEM** | Security Information and Event Management |
| **SOAR** | Security Orchestration Automation and Response |
| **WAF** | Web Application Firewall – межсетевой экран уровня приложения |
| **IaC** | Infrastructure as Code – инфраструктура как код |
| **CI/CD** | Continuous Integration / Continuous Delivery |
| **ПДн** | Персональные данные |
| **КИИ** | Критическая информационная инфраструктура |
| **ГосСОПКА** | Государственная система обнаружения и предупреждения компьютерных атак |
