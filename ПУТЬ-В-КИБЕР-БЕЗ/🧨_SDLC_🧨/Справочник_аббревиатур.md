# 📖 Справочник аббревиатур AppSec



> Всего терминов: **153**

---


## A

- **AES** – Advanced Encryption Standard (стандарт симметричного шифрования)
- **API** – Application Programming Interface (программный интерфейс приложения)
- **APK** – Android Package Kit (формат установочного пакета Android)
- **AppSec** – Application Security (безопасность приложений)
- **AST** – Abstract Syntax Tree (абстрактное синтаксическое дерево)

## B

- **BSIMM** – Building Security In Maturity Model (модель зрелости встроенной безопасности)

## C

- **CA** – Certificate Authority (центр сертификации (удостоверяющий центр))
- **CERT/SEI** – Computer Emergency Response Team / Software Engineering Institute (команда реагирования на инциденты / Институт программной инженерии (CMU))
- **CI** – Continuous Integration (непрерывная интеграция)
- **CI/CD** – Continuous Integration / Continuous Delivery (непрерывная интеграция / непрерывная поставка)
- **CISA** – Cybersecurity and Infrastructure Security Agency (Агентство по кибербезопасности и защите инфраструктуры (США))
- **CNA** – CVE Numbering Authority (организация, уполномоченная присваивать CVE)
- **CNCF** – Cloud Native Computing Foundation (фонд облачных (нативных) вычислений)
- **CORS** – Cross-Origin Resource Sharing (обмен ресурсами между источниками)
- **CPE** – Common Platform Enumeration (стандарт описания платформ и продуктов (NIST))
- **CSIRT** – Computer Security Incident Response Team (команда реагирования на инциденты компьютерной безопасности)
- **CSP** – Content Security Policy (политика безопасности контента)
- **CSRF** – Cross-Site Request Forgery (межсайтовая подделка запросов)
- **CSS** – Cascading Style Sheets (каскадные таблицы стилей)
- **CVE** – Common Vulnerabilities and Exposures (реестр известных уязвимостей)
- **CVSS** – Common Vulnerability Scoring System (система оценки критичности уязвимостей (0-10))
- **CWE** – Common Weakness Enumeration (каталог типов слабостей (уязвимостей))

## D

- **DAST** – Dynamic Application Security Testing (динамическое тестирование безопасности приложений)
- **DB** – Database (база данных)
- **DDoS** – Distributed Denial of Service (распределённый отказ в обслуживании)
- **DFD** – Data Flow Diagram (диаграмма потоков данных)
- **DLP** – Data Loss Prevention (предотвращение утечек данных)
- **DNS** – Domain Name System (система доменных имён)
- **DoS** – Denial of Service (отказ в обслуживании)
- **DREAD** – Damage, Reproducibility, Exploitability, Affected users, Discoverability (ущерб, воспроизводимость, эксплуатируемость, затронутые пользователи, обнаруживаемость)

## E

- **E2E** – End-to-End (сквозное тестирование)
- **EDR** – Endpoint Detection and Response (обнаружение и реагирование на конечных точках)
- **EPSS** – Exploit Prediction Scoring System (система прогнозирования вероятности эксплуатации)

## F

- **FR** – Functional Requirements (функциональные требования)

## G

- **GDPR** – General Data Protection Regulation (Общий регламент по защите данных (ЕС))
- **GPG** – GNU Privacy Guard (программа шифрования и цифровой подписи)

## H

- **HMAC** – Hash-based Message Authentication Code (код аутентификации сообщений на основе хэш-функции)
- **HSM** – Hardware Security Module (аппаратный модуль безопасности)
- **HSTS** – HTTP Strict Transport Security (строгая транспортная безопасность HTTP)
- **HTML** – HyperText Markup Language (язык гипертекстовой разметки)
- **HTTP** – HyperText Transfer Protocol (протокол передачи гипертекста)
- **HTTPS** – HyperText Transfer Protocol Secure (защищённый протокол передачи гипертекста)

## I

- **IaC** – Infrastructure as Code (инфраструктура как код)
- **IAM** – Identity and Access Management (управление идентификацией и доступом)
- **IAST** – Interactive Application Security Testing (интерактивное тестирование безопасности приложений)
- **IBM** – International Business Machines (корпорация IBM)
- **IDE** – Integrated Development Environment (интегрированная среда разработки)
- **IDOR** – Insecure Direct Object Reference (небезопасная прямая ссылка на объект)
- **IDS** – Intrusion Detection System (система обнаружения вторжений)
- **IP** – Internet Protocol (межсетевой протокол)
- **IPA** – iOS App Store Package (формат установочного пакета iOS)
- **IPS** – Intrusion Prevention System (система предотвращения вторжений)
- **ISO/IEC** – International Organization for Standardization / International Electrotechnical Commission (Международная организация по стандартизации / Международная электротехническая комиссия)

## J

- **JSON** – JavaScript Object Notation (текстовый формат обмена данными)
- **JWT** – JSON Web Token (веб-токен в формате JSON)

## K

- **K8s** – Kubernetes (система оркестрации контейнеров)
- **KEV** – Known Exploited Vulnerabilities (каталог известных эксплуатируемых уязвимостей (CISA))

## L

- **LFI** – Local File Inclusion (включение локальных файлов)
- **LINDDUN** – Linkability, Identifiability, Non-repudiation, Detectability, Disclosure, Unawareness, Non-compliance (угрозы приватности: связываемость, идентифицируемость, неотказуемость, обнаруживаемость, раскрытие, неосведомлённость, несоответствие)

## M

- **MASTG** – Mobile Application Security Testing Guide (руководство по тестированию безопасности мобильных приложений)
- **MASVS** – Mobile Application Security Verification Standard (стандарт проверки безопасности мобильных приложений)
- **MFA** – Multi-Factor Authentication (многофакторная аутентификация)
- **MITM** – Man-in-the-Middle (атака «человек посередине»)
- **MITRE** – (некоммерческая организация, оператор реестра CVE) (организация-оператор реестра CVE)
- **MR** – Merge Request (запрос на слияние (в Git))
- **MTTR** – Mean Time To Repair/Remediate (среднее время восстановления/устранения)
- **MVP** – Minimum Viable Product (минимально жизнеспособный продукт)

## N

- **NFR** – Non-Functional Requirements (нефункциональные требования)
- **NIST** – National Institute of Standards and Technology (Национальный институт стандартов и технологий (США))
- **NVD** – National Vulnerability Database (национальная база данных уязвимостей (США, NIST))

## O

- **OAuth** – Open Authorization (открытый протокол авторизации)
- **OCI** – Open Container Initiative (инициатива открытых контейнеров)
- **OCTAVE** – Operationally Critical Threat, Asset and Vulnerability Evaluation (оценка операционно критичных угроз, активов и уязвимостей (организационный уровень))
- **OS** – Operating System (операционная система)
- **OSV** – Open Source Vulnerabilities (открытая база уязвимостей открытого ПО (Google))
- **OTP** – One-Time Password (одноразовый пароль)
- **OWASP** – Open Web Application Security Project (открытый проект безопасности веб-приложений)

## P

- **PASTA** – Process for Attack Simulation and Threat Analysis (процесс моделирования атак и анализа угроз)
- **PCI DSS** – Payment Card Industry Data Security Standard (стандарт безопасности данных индустрии платёжных карт)
- **PKI** – Public Key Infrastructure (инфраструктура открытых ключей)
- **PoC** – Proof of Concept (доказательство концепции (работоспособности эксплойта))
- **PR** – Pull Request (запрос на включение (в Git))

## Q

- **QA** – Quality Assurance (обеспечение качества)

## R

- **RASP** – Runtime Application Self-Protection (самозащита приложения во время выполнения)
- **RBAC** – Role-Based Access Control (управление доступом на основе ролей)
- **RCE** – Remote Code Execution (удалённое выполнение кода)
- **REST** – Representational State Transfer (архитектурный стиль API (передача состояния представления))
- **RFI** – Remote File Inclusion (включение удалённых файлов)
- **RPO** – Recovery Point Objective (целевая точка восстановления (допустимая потеря данных))
- **RSS** – Really Simple Syndication (формат веб-лент (подписки на обновления))
- **RTO** – Recovery Time Objective (целевое время восстановления)

## S

- **SAMM** – Software Assurance Maturity Model (модель зрелости обеспечения гарантий безопасности ПО)
- **SAST** – Static Application Security Testing (статическое тестирование безопасности приложений)
- **SBOM** – Software Bill of Materials (ведомость (спецификация) состава ПО)
- **SCA** – Software Composition Analysis (анализ состава программного обеспечения)
- **SDLC** – Software Development Life Cycle (жизненный цикл разработки ПО)
- **SIEM** – Security Information and Event Management (управление событиями и информацией о безопасности)
- **SLA** – Service Level Agreement (соглашение об уровне сервиса)
- **SMS** – Short Message Service (служба коротких сообщений)
- **SOAP** – Simple Object Access Protocol (протокол обмена XML-сообщениями)
- **SOAR** – Security Orchestration, Automation and Response (оркестрация, автоматизация и реагирование на инциденты)
- **SOC** – Security Operations Center (центр операций безопасности)
- **SPDX** – Software Package Data Exchange (формат обмена данными о пакетах ПО (Linux Foundation))
- **SQL** – Structured Query Language (структурированный язык запросов)
- **SQLi** – SQL Injection (инъекция SQL)
- **SSDF** – Secure Software Development Framework (структура безопасной разработки ПО (NIST SP 800-218))
- **SSDLC** – Secure Software Development Life Cycle (безопасный жизненный цикл разработки ПО)
- **SSH** – Secure Shell (защищённая оболочка (протокол удалённого доступа))
- **SSL** – Secure Sockets Layer (протокол защищённых сокетов (предшественник TLS))
- **SSRF** – Server-Side Request Forgery (подделка серверных запросов)
- **SSTI** – Server-Side Template Injection (инъекция шаблонов на стороне сервера)
- **STRIDE** – Spoofing, Tampering, Repudiation, Information disclosure, DoS, Elevation of privilege (подмена, вмешательство, отказ, раскрытие, отказ в обслуживании, повышение привилегий)
- **SWID** – Software Identification (идентификация ПО (ISO/IEC 19770-2))

## T

- **TCP** – Transmission Control Protocol (протокол управления передачей)
- **TLS** – Transport Layer Security (протокол безопасности транспортного уровня)
- **TOTP** – Time-based One-Time Password (одноразовый пароль на основе времени)
- **TTL** – Time To Live (время жизни (токена/записи))

## U

- **UDP** – User Datagram Protocol (протокол пользовательских датаграмм)
- **UI** – User Interface (пользовательский интерфейс)
- **URI** – Uniform Resource Identifier (унифицированный идентификатор ресурса)
- **URL** – Uniform Resource Locator (унифицированный указатель ресурса)
- **UX** – User Experience (пользовательский опыт)

## V

- **VAST** – Visual, Agile, Simple Threat modeling (визуальное, гибкое, простое моделирование угроз)
- **VPN** – Virtual Private Network (виртуальная частная сеть)

## W

- **WAF** – Web Application Firewall (межсетевой экран для веб-приложений)

## X

- **XML** – eXtensible Markup Language (расширяемый язык разметки)
- **XSS** – Cross-Site Scripting (межсайтовый скриптинг)
- **XXE** – XML External Entity Injection (инъекция внешних сущностей XML)

## Y

- **YAML** – YAML Ain't Markup Language (формат данных (человекочитаемый))
- **YDB** – Yandex Database (база данных Яндекса)

## Z

- **ZAP** – Zed Attack Proxy (инструмент OWASP для тестирования безопасности веб-приложений)
- **Zero-day** – zero-day vulnerability (уязвимость нулевого дня (без известного фикса))

## Б

- **БД** – Database (база данных)
- **БДУ** – Threat Data Bank (банк данных угроз (ФСТЭК))

## Г

- **ГИС** – State Information System (государственная информационная система)
- **ГосСОПКА** – State System for Detection, Prevention and Elimination of Computer Attacks (государственная система обнаружения, предупреждения и ликвидации последствий компьютерных атак)
- **ГОСТ** – State Standard (государственный стандарт (РФ))

## И

- **ИБ** – Information Security (информационная безопасность)
- **ИСПДн** – Personal Data Information System (информационная система персональных данных)

## К

- **КИИ** – Critical Information Infrastructure (критическая информационная инфраструктура)
- **КоАП** – Administrative Offences Code (Кодекс об административных правонарушениях)

## М

- **МЭ** – Firewall (межсетевой экран)

## Н

- **НСД** – Unauthorized Access (несанкционированный доступ)

## П

- **ПДн** – Personal Data (персональные данные)
- **ПО** – Software (программное обеспечение)

## Р

- **РКН** – Roskomnadzor (Роскомнадзор (надзор в сфере связи, ИТ и массовых коммуникаций))
- **РФ** – Russian Federation (Российская Федерация)

## С

- **СЗИ** – Information Security Tools (средства защиты информации)
- **СУИБ** – Information Security Management System (система управления информационной безопасностью)

## У

- **УЗ** – Protection Level (уровень защищённости (ИСПДн))
- **УК** – Criminal Code (Уголовный кодекс)

## Ф

- **ФЗ-152** – Federal Law No. 152 «On Personal Data» (федеральный закон №152 «О персональных данных»)
- **ФСТЭК** – Federal Service for Technical and Export Control (Федеральная служба по техническому и экспортному контролю)
