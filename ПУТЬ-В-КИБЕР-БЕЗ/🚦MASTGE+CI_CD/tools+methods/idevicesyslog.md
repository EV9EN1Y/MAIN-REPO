## MASTG-TEST-0296 - Sensitive Data Exposure Through Insecure Logging

-------

**«Чувствительные данные не должны попадать в системные логи»**

- Нужно поймать логи приложения (`idevicesyslog`, Xcode console) во время работы.
    
- Тест провален, если в логах есть пароли, токены, сессии, личные данные.


---------

###### devicesyslog - это консольная утилита для просмотра логов

`idevicesyslog` - это командная строка, которая выводит системные логи с подключенного iPhone прямо в терминал. Никакого GUI, только чистый поток событий. Она входит в набор инструментов `libimobiledevice` и работает как на macOS, так и на Linux

> это аналог `adb logcat` для Android, только для iOS

```q

----------------------------------------

Лог-агрегаторы (Киби/ELK)
🔴 Очень высокая сложность
Для enterprise-масштаба - централизованный сбор логов со всех устройств

----------------------------------------
```

###### выполню тестирование ios приложения MeetWay (соц - сеть) c помощью idevicesyslog

- [[0_MeetWay]]

>  `idevicesyslog` - это настоящий "швейцарский нож" для сбора логов. В отличие от графических утилит, он работает на macOS, Linux и даже Windows, позволяя гибко фильтровать данные и встраивать команду в скрипты для автоматизации

пользоваться - невероятно просто!

ставлю на комп `brew install libimobiledevice)`


далее подключаюсь к логам конкретно моего приложения 

`idevicesyslog -p MeetWay`

Отсекает 99% мусора от системных служб

(телефон через шнур подключен к маку)

и программа сразу показывает динамически - все логи системные, что есть в моем приложении! их оч много, и нужно в этом множестве логов искать только конкретные мне  

<img src="../../../assets/Снимо2026-04-0816.05.41.png" alt="Скрин" style="width: 90%; max-width: 1000px;" />



вот так можно выполнять поиск только по конкретным логам (по ключевым словам)



`idevicesyslog -m "token"` 
Для быстрого поиска конкретных данных в реальном времени


---------

Тихий режим + логи только от нужного приложения 
`idevicesyslog -q -p MeetWay`


--------
Точный поиск
`idevicesyslog -p MeetWay -m "token"`

вот ключи которые можно искать
` "token" -m "pass" -m "jwt" -m "secret" -m "key" -m "api" -m "auth" -m "session" -m "cookie" -m "credit" -m "cvv" -m "pin" -m "login" -m "signin" -m "password" -m "private"`


---------

вот так можно отсеять лишние логи , убрать вручную шум
`idevicesyslog -p MeetWay -e "debug" -e "info"`


---

запись результатов на файл
`idevicesyslog -q -p MeetWay -o ~/Desktop/meetway_logs.txt`


---------

`Ctrl+C`  - ОСНОВКА ПРОЦЕССА ПРОСМОТРА ЛОГОВ

и если записал все в файл - далее через grep можно искать нужные совпадеиния

`grep -E "token|password|myID|kkr15" ~/Desktop/meetway_logs.txt`

--------


#### вот так все это делается

```q
запускаю процесс с сохранением в файл

idevicesyslog -p MeetWay > ~/Desktop/meetway_logs.txt 2>&1

изучаю приложние, тыкаю кнопки итд

 потом выхожу из сканера Ctrl+C


и потом в данном файле уже ищу по ключевым словам

grep -E "token|pass|jwt|secret|key|api|auth|session|cookie|credit|cvv|pin|login|password|fcmToken|myID|private|id" ~/Desktop/meetway_logs.txt
```
