
# MASTG-TEST-0317: Некорректные режимы симметричного шифрования

--------

тест проверит  наличие - использования **опасного режима шифрования ECB**, когда один и тот же блок открытого текста даёт одинаковый блок шифротекста. Это позволяет анализировать паттерны в данных.


ECB не скрывает паттерны. Если зашифровать картинку в режиме ECB, оригинал всё равно будет виден невооружённым глазом (эффект "Пингвина" от OpenSSL)

вот как бывает еще
отличие от других режимов:

- **ECB** - каждый блок шифруется отдельно. Одинаковые блок -> одинаковый результат. Позволяет анализировать паттерны
    
- **CBC** - каждый следующий блок зависит от предыдущего. Плюс нужен случайный IV. Паттерны скрыты
    
- **GCM** - аутентифицированное шифрование (AES-GCM). Самый современный и безопасный вариант

---------

В iOS более новая версия `CryptoKit` не поддерживает режим ECB и, следовательно, не подвержена этой проблеме, поскольку поддерживает только безопасные режимы шифрования, такие как AES-GCM и ChaCha20-Poly1305. Однако приложения могут использовать более старую версию `CommonCrypto` или другие сторонние библиотеки, которые могут поддерживать режим ECB. В этом случае необходимо убедиться, что режим ECB не используется


----------



вот как можно тестировать  - также через бинарник

```q
# 1. Найти импорт CCCrypt (основная функция CommonCrypto)
is | grep -E "CCCrypt"

# 2. Найти все вызовы CCCrypt и посмотреть перекрёстные ссылки
axt sym.imp.CCCrypt    (если найден был CCCrypt)

# 3. Для каждого найденного адреса (через axt) смотрим код и ищем options
# Переходим по адресу (например, 0x10004b560)
s 0x10004b560

# 4. Показать 20 строк кода перед вызовом (ищем mov x?, #0x2 или mov w?, #0x2)
pd 20

# 5. Поиск по всем вызовам CCCrypt значения константы ECB (0x2)
/ 0x00000002

# 6. Поиск строки kCCOptionECBMode в бинарнике (если не затерлась)
/ kCCOptionECBMode

# 7. Поиск всех вызовов CCCrypt через поиск инструкции вызова
/ call sym.imp.CCCrypt

# 8. Для проверки альтернативных криптобиблиотек
is | grep -E "EVP_EncryptInit|AES_set_encrypt_key"

# 9. Поиск иных признаков ECB (режим в других библиотеках)
/ ECB

-------

r2 -qc "is | grep CCCrypt; axt sym.imp.CCCrypt 2>/dev/null; / 0x00000002" ./MeetWay.debug.dylib
```
