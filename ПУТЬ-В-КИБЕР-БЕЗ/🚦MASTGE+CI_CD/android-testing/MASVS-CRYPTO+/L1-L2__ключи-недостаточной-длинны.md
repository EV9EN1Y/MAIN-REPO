# MASTG-TEST-0208: Insufficient Key Sizes
https://mas.owasp.org/MASTG/tests/android/MASVS-CRYPTO/MASTG-TEST-0208/


**не использует ли приложение криптографические ключи недостаточной длины** (например, RSA-1024 или AES-128), которые не считаются безопасными

-------

чек - лист поиска

1. **`KeyGenerator.getInstance`** -  чтобы найти место, где создается экземпляр для симметричного шифрования. Обрати внимание на параметр, передаваемый в метод
    
2. **`KeyGenerator.init`** - метод, который задает размер ключа для `KeyGenerator`
    
3. **`KeyPairGenerator.getInstance`** - используется для поиска места создания экземпляра для асимметричного шифрования (RSA, EC)
    
4. **`KeyPairGenerator.initialize`** - метод, который задает размер ключа для `KeyPairGenerator`
    
5. **`Cipher.getInstance`** - в контексте инициализации с ключом. Ищи вызовы, где передается алгоритм, и затем прослеживай, какой ключ используется
    
6. **`KeyStore`** - методы `getEntry`, `getKey` и т.д. Позволяют найти, где ключи загружаются из хранилища
    
7. **`KeyGenParameterSpec.Builder`** - для Android M+ (API 23), этот класс используется для создания спецификаций ключей с заданными параметрами. Ищи метод `setKeySize`
    
8. **`KeyPairGeneratorSpec`** - для старых версий Android, где задаются параметры генерации ключевой пары (размер ключа обычно указывается в конструкторе)
    
9. **`RSA`** - простое вхождение этого слова в сочетании с `KeyPairGenerator` или `Cipher`. Позволяет найти места, где явно используется алгоритм RSA
    
10. **`AES`** - аналогично, ищи в сочетании с `KeyGenerator` или `Cipher`
    
11. **`EC`** - для поиска использования эллиптических кривых

KeyStore не используется в коде приложения используется EncryptedSharedPreferences
KeyGenParameterSpec не используется в коде приложения используется EncryptedSharedPreferences через MasterKey Builder
KeyPairGeneratorSpec не используется
RSA не используется в коде приложения
EC не используется в коде приложения

единственное место где используются криптографические ключи это

✅✅🔥  EncryptionUtil java использует AES/GCM/NoPadding с SecretKeySpec для AES размер ключа 256 бит это безопасно

✅✅🔥   SecureStorage java использует EncryptedSharedPreferences с MasterKey KeyScheme AES256 GCM это тоже 256 бит безопасно
