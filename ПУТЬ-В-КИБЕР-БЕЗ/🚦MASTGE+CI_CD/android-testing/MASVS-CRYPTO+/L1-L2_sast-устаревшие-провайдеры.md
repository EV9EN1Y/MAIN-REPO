# MASTG-TEST-0312: References to Explicit Security Provider in Cryptographic APIs
https://mas.owasp.org/MASTG/tests/android/MASVS-CRYPTO/MASTG-TEST-0312/

**ЭТОТ ТЕСТ про то, не указывает ли приложение явно устаревший или удаленный криптопровайдер** при вызове методов `getInstance()` (например, `Cipher.getInstance()`, `KeyGenerator.getInstance()`). Это может привести к тому, что приложение перестанет работать на новых версиях Android или будет использовать небезопасные реализации

В Android есть несколько криптографических провайдеров 
(например, `BC` - BouncyCastle, `Crypto`)
Некоторые из них были **удалены** или **объявлены устаревшими** в новых версиях Android. Если приложение явно указывает такой провайдер, оно может упасть на устройствах с Android 9+ или использовать небезопасные алгоритмы

**Удаленные провайдеры:**

- `Crypto` - удален в Android 9 (API 28)
   
- `BC` (BouncyCastle) - удален в Android 12 (API 31)
   

**Безопасный и рекомендуемый провайдер:**

- `AndroidOpenSSL` (Conscrypt) - используется по умолчанию и активно поддерживается
   

**Исключение:** Указание провайдера для `KeyStore` (`"AndroidKeyStore"`) - это **безопасно** и необходимо для работы с системным хранилищем ключей

## чек мест (но лучше общий поиск провайдеров по проекту делать)

- **`Cipher.getInstance`** — ищи вызовы для шифрования/дешифрования
    
- **`KeyGenerator.getInstance`** — ищи вызовы для генерации ключей
    
- **`KeyPairGenerator.getInstance`** — ищи вызовы для генерации асимметричных ключей
    
- **`Signature.getInstance`** — ищи вызовы для подписи/верификации
    
- **`SecretKeyFactory.getInstance`** — ищи вызовы для преобразования ключей
    
- **`Mac.getInstance`** — ищи вызовы для HMAC
    
- **`KeyStore.getInstance`** — ищи вызовы для хранилища ключей (если там не `"AndroidKeyStore"`— это подозрительно)
    
- **`"BC"`** — ищи явное указание провайдера BouncyCastle (удален в Android 12)
    
- **`"Crypto"`** — ищи явное указание провайдера Crypto (удален в Android 9)
    
- **`"SC"`** — ищи явное указание провайдера BouncyCastle в версии для смарт-карт
    
- **`"Conscrypt"`** — ищи явное указание стандартного провайдера (если он указан явно, это может быть проблемой совместимости)
    
- **`"AndroidOpenSSL"`** — ищи явное указание стандартного провайдера (если он указан явно, это может быть проблемой совместимости)
    
- **`"AndroidKeyStore"`** — ищи указание провайдера для Keystore (это безопасно, но если он указан в других контекстах, кроме `KeyStore.getInstance`, это подозрительно)

### Список опасных провайдеров для поиска

1. **`"Crypto"`** — удален полностью в Android 9 (API 28). Устарел еще с Android 7.0 (API 24). Любое его использование вызовет краш на новых версиях 
    
2. **`"BC"` (BouncyCastle)** — удален в Android 12 (API 31). Устарел начиная с Android 9 (API 28). Если приложение явно укажет этот провайдер в `getInstance()`, оно упадет
   
  исключение

Указывать провайдер безопасно **только для `KeyStore.getInstance("AndroidKeyStore")`**. Это необходимо для работы с системным хранилищем ключей и не считается уязвимостью

----

пример  уязвимости!

`Cipher.getInstance("...", "BC")` или `KeyGenerator.getInstance("...", "Crypto")`
