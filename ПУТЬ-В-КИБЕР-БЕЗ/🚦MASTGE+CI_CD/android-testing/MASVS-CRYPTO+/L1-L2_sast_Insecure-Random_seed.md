# MASTG-TEST-0204: Insecure Random API Usage
https://mas.owasp.org/MASTG/tests/android/MASVS-CRYPTO/MASTG-TEST-0204/

Этот тест проверяет, не использует ли приложение классы `java.util.Random` или `Math.random()`для генерации значений, которые должны быть непредсказуемыми (например, пароли, токены, криптографические ключи, соли). Эти генераторы основаны на линейном конгруэнтном методе и дают предсказуемую последовательность, если известен seed (начальное число). Злоумышленник, зная алгоритм и seed, может восстановить все сгенерированные значения

## Перепроверка OpenClaw (Скайнет) – 03.07.2026

### Методология
Декомпиляция APK через jadx, grep по всему коду приложения `com.evgeniy.meetway` (298 файлов).

### Результаты поиска insecure random в коде приложения

| Поиск | Найден в коде приложения? | Где именно |
|-------|--------------------------|------------|
| `java.util.Random` | ❌ Нет | Только в сторонних библиотеках (Google, Kotlin stdlib, okhttp, gRPC и т.д.) |
| `Math.random()` | ❌ Нет | Только в сторонних библиотеках |
| `new Random(` | ❌ Нет | Только в сторонних библиотеках |
| `kotlin.random.Random` | ✅ Да, 1 место | `ChatsScreen.kt` – симуляция уровня аудио при записи голоса (UI-визуализация, non-sensitive) |

### SecureRandom (правильное использование)

| Файл | Назначение | Вердикт |
|------|-----------|---------|
| `EncryptionUtil.java` | Генерация IV для AES-GCM и случайного ключа | ✅ SecureRandom, всё правильно |

| `SecureStorage.java` | Генерация случайного ключа шифрования | ✅ SecureRandom, всё правильно |

### `UUID.randomUUID()` – безопасно
Используется в:
- `ProfileViewModel.java` – генерация ID постов
- `LocatesUser.java` / `UserDataCellsInfo.java` – генерация ID локаций/ячеек
- `VideoProcessor.java` / `CameraXRecorder.java` – имена файлов
- `RoadMapScreenKt.java` / `LentaMainViewScreenKt.java` – ID элементов UI

`UUID.randomUUID()` внутри использует `SecureRandom`, так что это криптостойко.

### Вердикт
**Работа подтверждена. Тест пройден (PASS).**

Insecure random (`java.util.Random`, `Math.random()`) для генерации sensitive данных (ключи, токены, пароли, IV, nonce, session ID) **не используется** в коде MeetWay Android.

Единственное использование `kotlin.random.Random` – для симуляции уровня громкости аудио при записи (чисто UI, non-sensitive).

Критически важные криптографические операции (генерация ключей, IV, PIN) используют `java.security.SecureRandom` – корректно.
