> radare2 - это консольный инструмент для реверс-инжиниринга (дизассемблер).  
Он позволяет заглянуть внутрь готового приложения, когда нет исходного кода.  
С его помощью можно искать функции, строки, анализировать, как работает программа

------

#### ЗАЧЕМ НУЖЕН В ТЕСТИРОВАНИИ БЕЗОПАСНОСТИ

1. Проверить, использует ли приложение опасные функции (например, isExcludedFromBackup)
    
2. Найти hardcoded ключи или пароли, вшитые в бинарник
    
3. Понять логику работы защиты (обфускация, антиотладка)
    
4. Подтвердить уязвимость, когда нет доступа к исходникам
    

---

#### КОГДА ИСПОЛЬЗОВАТЬ

- У тебя есть только .ipa файл (без исходного кода в Xcode)
    
- Ты тестируешь чужое приложение из App Store или от клиента
    
- Хочешь проверить, сработала ли защита на уровне компиляции
    

#### КОГДА НЕ ИСПОЛЬЗОВАТЬ

- У тебя есть полный исходный код в Xcode (там поиск через Cmd+Shift+F быстрее)


##### БАЗОВЫЕ КОМАНДЫ


ЗАПУСК АНАЛИЗА

```bash
r2 -A ./название_бинарника  

-A - флаг, который запускает автоматический анализ (ищет функции, строки, ссылки)  
Пример: r2 -A MeetWay

# ПОИСК СТРОКИ (САМАЯ ВАЖНАЯ КОМАНДА)

/ искомая_строка  

Ищет строку в бинарнике (например, название функции)  
Пример: / isExcludedFromBackup  
Если ничего не нашло - значит, строка отсутствует

# ВЫХОД ИЗ ПРОГРАММЫ

q  
Выход из radare2 (quit)
```

------

###### ДОПОЛНИТЕЛЬНЫЕ ПОЛЕЗНЫЕ КОМАНДЫ 

```q
aaa  
Запустить анализ, если не использовали флаг -A при старте

afl  
Показать список всех найденных функций

izz  
Показать все строки (strings), которые есть в бинарнике

s main  
Переместиться к функции main (или любой другой по имени)

pdf  
Показать дизассемблированный код текущей функции

axt @ адрес  
Найти все ссылки на указанный адрес (кто вызывает эту функцию)

VV  
Визуальный режим (граф выполнения функции) - нажмите VV, потом Enter

rabin2 -z ./бинарник  
Показать все строки из командной строки (без запуска radare2)

```

-------
###### ГДЕ ВЗЯТЬ БИНАРНИК ДЛЯ АНАЛИЗА  

```
Из .xcarchive (если есть исходник):  
~/Library/Developer/Xcode/Archives/ -> показать содержимое пакета -> Products/Applications/*.app/ -> файл без расширения

Из .ipa (чужое приложение):  
Распаковать .ipa как zip -> Payload/*.app/ -> файл без расширения
```

###### КОГДА radare2 РЕАЛЬНО НУЖЕН

1. Нет исходного кода (тестируешь чужое приложение)
    
2. Проверяешь обфускацию (разработчик специально запутал код)
    
3. Ищешь скрытые вызовы, которых нет в исходниках (сторонние библиотеки)
    
4. Хочешь показать в отчете, что нашел уязвимость, не имея доступа к коду
