iMazing - это графическая утилита для Windows и macOS, которая позволяет управлять iOS-устройствами и извлекать из них данные. В отличие от Xcode, она работает с любым iPhone, не требуя исходников, и не требует джейлбрейка для большинства операций

-------  

###### ЧЕМ ПОЛЕЗЕН iMazing ДЛЯ AppSec  

в бесплатной версии есть:

==1. ПРОСМОТР ФАЙЛОВОЙ СИСТЕМЫ ПРИЛОЖЕНИЯ
   free

Ты можешь залезть в папку любого установленного приложения и посмотреть, что оно хранит на устройстве. Это позволяет проверить, лежат ли токены, ключи или пользовательские данные в открытом виде в файлах .plist, базах данных SQLite или обычных txt-файлах

==2. РАБОТА С РЕЗЕРВНЫМИ КОПИЯМИ
    free

iMazing создает резервные копии устройства или позволяет анализировать уже существующие (iTunes/iCloud). Ты можешь увидеть, какие данные приложения попадают в бэкап, и, главное, в каком виде — открытом или зашифрованном.

==3. ИЗВЛЕЧЕНИЕ И СОХРАНЕНИЕ ФАЙЛОВ
    free

Любой файл из папки приложения или из бэкапа можно скопировать на компьютер и открыть в любом редакторе. Это нужно, чтобы подтвердить, что данные действительно не защищены.

==4. ПРОСМОТР ДАННЫХ KEYCHAIN
    free

iMazing умеет отображать содержимое связки ключей (Keychain) приложения, если у вас есть доступ к устройству. Это позволяет проверить, правильно ли разработчик использует Keychain для хранения токенов и паролей.

==5. УПРАВЛЕНИЕ ПРИЛОЖЕНИЯМИ
    free

Можно скачать .ipa файл приложения прямо из App Store (если оно есть в вашей учетной записи) и сохранить его для последующего статического анализа в radare2 или Ghidra. Это полезно, когда нужно изучить чужое приложение, но нет возможности его расшифровать на устройстве.

==6. ЛОГИ УСТРОЙСТВА
    free

iMazing показывает системные логи iOS. Это помогает найти утечку данных через консоль, даже если разработчик забыл убрать `print` или `NSLog` в релизной сборке.

==7. РАБОТА БЕЗ ДЖЕЙЛБРЕЙКА
   

Это главное преимущество. Всё перечисленное выше работает на обычном, невзломанном iPhone. Для AppSec-инженера это означает, что вы можете проверить защиту приложения на реальном устройстве, не тратя время на взлом.

 = = = = ==  == =  = = = = = = =  == 

в бесплатной версии не работает:

```q
- **Восстановление данных из бэкапа.** Если ты удалил приложение, а потом захочешь восстановить его данные из бэкапа — это платная функция. Но для проверки безопасности тебе это не нужно, тебе нужно просто _посмотреть_, какие данные лежат в бэкапе.
    
- **Экспорт всех данных разом.** Бесплатно можно экспортировать данные по одному типу за раз. Но для точечной проверки конкретного файла с токеном это не проблема.
    
- **Массовое управление устройствами (Configurator).** Функции для IT-админов, тебе не нужны.
    
- **CLI (Command Line Interface).** Для автоматизации через скрипты. Ты пока до этого не дошел.
```

###### КОГДА iMazing ОСОБЕННО ПОЛЕЗЕН  


- Нет доступа к исходному коду (тестируете чужое приложение)
    
- Нужно быстро проверить несколько приложений на наличие "дыр" в хранилище
    
- Хотите увидеть, что реально попадает в бэкап, без создания и разбора архивов вручную
    
- Проверяете, правильно ли работает Keychain
    
- Нужно вытащить .ipa приложения для статического анализа
   

-------

###### КОГДА iMazing НЕ НУЖЕН  

- У вас есть полный исходный код, и вы можете запустить приложение на симуляторе Xcode (там доступ к файлам проще и быстрее)
    
- Вам нужен только анализ кода (SAST), без проверки на реальном устройстве
    
- У вас уже есть джейлбрейкнутое устройство, и вы предпочитаете работать из командной строки
   

------

###### ЧТО iMazing НЕ УМЕЕТ  


- Не заменяет дизассемблер (не покажет ассемблерный код)
    
- Не может расшифровать зашифрованные FairPlay-приложения на лету (нужен джейлбрейк для расшифровки)
    
- Не умеет изменять код или подписывать приложения (это к другим инструментам)
    
- Не является инструментом для динамического анализа в реальном времени (нет перехвата функций, как в Frida)
    

-------

###### БАЗОВЫЙ ФЛОУ ДЛЯ ТЕСТИРОВАНИЯ В iMazing  


1. Установить iMazing на компьютер и подключить iPhone.
    
2. Дождаться создания резервной копии (или создать вручную).
    
3. Выбрать нужное приложение в списке.
    
4. Нажать "Просмотреть файлы" (View Files) — откроется файловая система приложения.
    
5. Пройтись по ключевым папкам (Documents, Library/Preferences, Library/Caches).
    
6. Найти подозрительные файлы (.plist, .db, .json, .txt).
    
7. Сохранить их на компьютер и открыть.
    
8. Выполнить поиск по ключевым словам (token, password, key, user).
    
9. Сделать скриншоты для отчета.
    
10. Повторить для бэкапа: посмотреть, какие из этих файлов попали в резервную копию.
    

--------
ПОЛЕЗНЫЕ ФУНКЦИИ ДЛЯ AppSec  
------------------------------------

- "Извлечь приложение" (Extract App) — сохранить .ipa на диск.
    
- "Просмотреть данные приложения" (View App Data) — быстрый доступ к папке приложения.
    
- "Создать резервную копию" (Backup) — сделать свежий бэкап для анализа.
    
- "Показать в Finder" (Show in Finder) — быстро добраться до файлов на компьютере.
    
- "Keychain" — посмотреть содержимое связки ключей приложения.
    

------
МИНУСЫ И ОГРАНИЧЕНИЯ  
----------------------------

- Платная программа (есть триал, но с ограничениями).
    
- Не работает на Linux (только Windows и macOS).
    
- Некоторые данные могут быть не видны без джейлбрейка (например, полностью защищенный Keychain).
    
- Не подходит для автоматизации (нет CLI с богатыми возможностями).
   

---


ВЫВОД

iMazing — это универсальный "швейцарский нож" для анализа данных iOS-приложений без джейлбрейка. Он не заменяет Xcode и radare2, но закрывает важную нишу: быструю проверку того, что приложение реально хранит на устройстве и что из этого улетает в бэкап. Особенно полезен, когда исходников нет, а устройство есть
