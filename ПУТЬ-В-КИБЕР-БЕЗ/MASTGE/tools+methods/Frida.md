ЧТО ЭТО

==frida - это инструмент для динамической инструментации. проще говоря, она позволяет внедрять свой javascript-код в работающее приложение прямо на телефоне. ты можешь перехватывать вызовы функций, менять их返回值, смотреть, какие данные передаются, и обходить защиту (ssl pinning, jailbreak detection, root detection)==

----

###### ЗАЧЕМ frida В ТЕСТИРОВАНИИ БЕЗОПАСНОСТИ

1. обход ssl pinning. приложение не дает перехватить трафик через burp? frida отключает проверку сертификата за секунду
    
2. обход jailbreak/root detection. приложение отказывается работать на взломанном устройстве? frida подменяет функцию проверки и заставляет его думать, что устройство чистое.
    
3. перехват и подмена данных. можно посмотреть, какие аргументы передаются в функцию, и изменить их на лету. например, заменить сумму платежа или id пользователя.
    
4. дамп памяти. можно выгрузить память приложения и поискать там пароли, ключи, токены
    
5. вызов любых функций принудительно. можно дернуть функцию, которая обычно вызывается только после нажатия кнопки, и посмотреть, что будет.
   
---

###### КОГДА FRIDA НУЖНА 

- нужно обойти защиту (ssl pinning, jailbreak detection)
    
- нужно перехватить данные в реальном времени
    
- приложение не дает себя отлаживать
    
- есть устройство с джейлбрейком (или ты готов патчить приложение)
   

----------

 ###### КОГДА FRIDA НЕ НУЖНА

- есть исходный код и можно просто прочитать его в xcode
    
- если нужно - проверить статику (хардкодные ключи, отсутствие флагов)
    
- приложение не использует защиту (ssl pinning, jailbreak detection)
    
- например, запущен симулятор (там и без frida всё видно)
   

---

###### КАК ЭТО РАБОТАЕТ (КОРОТКО)

frida состоит из двух частей.

1. frida-server - программа, которая запускается на телефоне (требует root или jailbreak). она ждет команд с компьютера
    
2. frida-client - программа на компьютере (python, cli).  пишешь скрипт и отправляешь его на сервер, который внедряет его в приложение

###### БАЗОВЫЕ КОМАНДЫ (ТО, ЧТО РЕАЛЬНО НУЖНО)  


УСТАНОВКА (на комп)

```
pip install frida-tools

УСТАНОВКА FRIDA-SERVER НА ТЕЛЕФОН (IOS CYDIA/SILEO)

- добавить репозиторий [https://build.frida.re](https://build.frida.re/)
    
- установить пакет frida
```
   

ЗАПУСК FRIDA-SERVER НА ТЕЛЕФОНЕ (ЧЕРЕЗ SSH)

```
ssh root@ip_телефона  
frida-server &  
(или frida-server -D)
```

СПИСОК ЗАПУЩЕННЫХ ПРИЛОЖЕНИЙ НА ТЕЛЕФОНЕ

```
frida-ps -U
```

УСТАНОВКА FRIDA НА ANDROID 

```
adb root  
adb push frida-server /data/local/tmp/  
adb shell chmod 755 /data/local/tmp/frida-server  
adb shell /data/local/tmp/frida-server &
```

ПРИМЕР ПРОСТОГО СКРИПТА НА FRIDA (ПЕРЕХВАТ ВЫЗОВА ФУНКЦИИ)  


вот скрипт, который перехватывает вызов функции isExcludedFromBackup и логирует, для какого файла она вызывается

```javascript
// hook_isExcludedFromBackup.js
var NSURL = ObjC.classes.NSURL;
var originalSetResourceValue = NSURL['- setResourceValue:forKey:error:'];
Interceptor.attach(originalSetResourceValue.implementation, {
    onEnter: function(args) {
        var key = ObjC.Object(args[2]);
        if (key.toString() === "NSURLIsExcludedFromBackupKey") {
            var value = ObjC.Object(args[1]);
            console.log("[!] isExcludedFromBackup установлен в: " + value);
            console.log("[!] Для файла: " + ObjC.Object(args[0]));
        }
    }
});
```
запуск скрипта:

frida -U -l hook_isExcludedFromBackup.js com.твоего.приложения.bundleid

###### ЧТО FRIDA НЕ УМЕЕТ

- не работает на jailed устройстве без перепаковки приложения (но objection решает эту проблему)
    
- не анализирует статику (это кSemgrep , MobSF, IPA Auditor, radare2 и xcode)
    
- не создает резервные копии (это к iMazing)
    
- не может расшифровать бинарник из app store без джейлбрейка
   

---------------

БАЗОВЫЙ ФЛОУ ДЛЯ ТЕСТИРОВАНИЯ С FRIDA

1. установить frida-server на устройство (нужен джейлбрейк для ios или root для android)
    
2. запустить frida-server на устройстве
    
3. подключиться по usb
    
4. найти bundleid приложения (frida-ps -U)
    
5. запустить готовый скрипт с frida codeshare или написать свой
    
6. выполнить действие в приложении
    
7. смотреть вывод в терминале
    
8. если нужно обойти защиту - запустить скрипт обхода и потом перехватывать трафик через burp
   

-------------

ВАЖНО ЗНАТЬ

- frida требует root или jailbreak. но objection позволяет обойти это для некоторых задач (перепаковывает приложение с frida gadget).
    
- готовые скрипты с codeshare часто работают из коробки, но иногда нужно адаптировать под конкретное приложение.
    
- frida - это мощно, но требует практики. начни с готовых скриптов обхода ssl pinning, потом переходи к написанию своих.
    
- без frida ты не обойдешься при тестировании защищенных приложений уровня L2 и R.

ВЫВОД

frida - это швейцарский нож для динамического анализа. если приложение пытается тебе помешать (проверяет джейлбрейк, пининг сертификатов), ты берешь frida и отключаешь эту защиту. без нее ты не пройдешь тесты уровня L2 и R. но для начала (L1) она не обязательна. осваивай постепенно, не пытайся выучить всё сразу
