# Insecure APK Signature Version
https://mas.owasp.org/MASTG/tests/android/MASVS-RESILIENCE/MASTG-TEST-0224/#overview

этот тест про **безопасность подписи APK**, - про то, не использует ли приложение устаревший и дырявый метод подписи

тест провожу на приложении 👉 [[0_MeetWay]]

------

Тест **MASTG-TEST-0224** проверяет, использует ли приложение только **v1 (JAR) схему подписи**APK  Если да - это провал теста, потому что это небезопасно

- **В чем риск:** Старая v1 подпись уязвима для атаки **"Janus" (CVE-2017-13156)** 
- Злоумышленник может модифицировать APK (вставить вредоносный код), и при этом **подпись останется валидной** 

- **Как работает атака:** Файл становится одновременно и APK, и DEX. Система проверяет подпись по одной части (APK), а выполняет код из другой (DEX) 
    
- **Главная уязвимость:** Особенно опасна для устройств с **Android 5.0- 8.0**, которые не поддерживают новые схемы подписи 

------------


есть классная утилита! 
### apksigner

это официальная утилита из Android SDK Build Tools для **подписи APK-файлов** и **проверки их подписей**

что умеет `apksigner`:

- **Подписывать APK (`sign`)**: Накладывает цифровую подпись на приложение, используя ваш ключ (keystore) 
   
- **Проверять подпись (`verify`)**: Проверяет, что подпись APK валидна и будет принята на устройствах с разными версиями Android

- **Управлять ключами подписи (`rotate`)**: Позволяет менять ключи подписи для приложений, используя схему APK Signature Scheme v3 
    
поддерживает схемы ?

`apksigner` знает все схемы подписи и умеет ими управлять:

- **v1 (JAR signing)**: Традиционная, старая схема, уязвимая для атаки "Janus" 
- **v2 (APK Signature Scheme v2)**: Более безопасная схема, представленная в Android 7.0 (API 24) 
- **v3 и v3.1**: Схемы для поддержки ротации ключей и новых функций
- **v4**: Схема для стриминговой установки APK-файлов

смысл в том, что можно просто его запустить и проверить подпись!

-------

### скачиваю архив apksigner
```q
wget https://dl.google.com/android/repository/build-tools_r30.0.1-macosx.zip
```

### расспаковка
```q
unzip build-tools_r30.0.1-macosx.zip
```

### запуск проверки подписи!!
```sh
java -jar ~/android-11/lib/apksigner.jar verify --verbose ~/Desktop/meetway.apk
```

### вывод: 

приложение подписано **как минимум по схеме v2**, что является современным стандартом и не имеет уязвимости "Janus". Оно безопасно и соответствует требованиям MASVS-RESILIENCE
