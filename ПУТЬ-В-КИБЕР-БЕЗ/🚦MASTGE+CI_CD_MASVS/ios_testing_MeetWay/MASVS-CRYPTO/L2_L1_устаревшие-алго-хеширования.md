
# MASTG-TEST-0211: неработающие алгоритмы хеширования


**Че проверяет:** Не использует ли приложение криптографически сломанные хеш-функции (MD5, SHA-1) для защиты данных

**Почему это важно:** MD5 и SHA-1 сломаны - коллизии (разные данные дают одинаковый хеш) можно создать за минуты/часы. Если ими хешируют пароли или подписи - это критически плохо

**Вердикт:** FAIL  - >, если есть `CC_MD5`, `CC_SHA1`, `Insecure.MD5` или `Insecure.SHA1` в контексте безопасности

#### MD2, MD4, MD5, SHA-1   - все это ломается!

----------
