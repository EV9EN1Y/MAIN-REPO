# Мобильная часть

- MASVS – это чек-лист «что должно быть» для мобильных приложений (требования). Проверяется
  тестами из MASTG. ✅ да, это «чек» для тестов MASTG
- MASTG – это гайд «как проверить» каждое требование MASVS (тест-кейсы, шаги, инструменты)
https://mas.owasp.org

--------


# Веб/API часть

 WSTG - Web Security Testing Guide

- ==ASVS== – это чек-лист «что должно быть» для веб-приложений и API (требования, ~290 пунктов, уровни
  L1/L2/L3). Аналог MASVS, только для серверной части
- ==WSTG== – это гайд «как проверить» требования ASVS (тест-кейсы, ~91 штука). Аналог MASTG для веба

- Сайт: owasp.org/www-project-web-security-testing-guide/
- GitHub: github.com/OWASP/wstg (там же лежит WSTG Checklist – Excel со всеми ~91 тест-кейсом)





│ ASVS – требования «что» (веб/API) │ github.com/OWASP/ASVS       │ ~290 требований   ASVS (чек-лист, ТОГО ЧТО ДОЛЖНО БЫТЬ - ТРЕБОВАНИЯ К ЗАЩИТЕ ВЕБ)


──────────────────────-----------------──────────
│ WSTG – тесты «как» (веб)                 │        │ ~113 тест-кейс (v4.2)  это тесты WSTG (процедуры, как проверять, КАК ТЕСТИРОВАТЬ!!!)

https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/
