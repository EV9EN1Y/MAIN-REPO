# Уязвимости в многофакторной аутентификации 2FA

уязвимости, которые могут возникнуть в механизмах многофакторной аутентификации. 

двухфакторную аутентификацию (2FA)

Проверка биометрических факторов

ввода как традиционного пароля, 

так и ввод временного проверочного кода с физического устройства

двухфакторая аутентификация явно безопаснее, но в ее реализации могут быть грубые ошибки

должно быть два разны пароля и получение их раными способами, а не два способа для одного секрета

==токен RSA это - Токены, использующие **RSA-шифрование** для генерации одноразовых кодов (OTP). 
когда  пример (Время: 14:30:00 → Код: 123456) на устройстве локально без сети работает. 
1. **Синхронизированные часы** (токен и сервер)
    
2. Каждые **30-60 секунд** новый код
    
3. **Алгоритм:** Текущее время + секретный ключ → код
пример = Google Authenticator
