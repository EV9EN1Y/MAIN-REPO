#  Linux   Windows

-----
## Файловая система

В Windows диски — это "полки", в Linux — это единое "дерево".

- **Windows (Физическое разделение):**
    
    - Есть диск C: (система), D: (данные), E: (флешка).
        
    - Корень каждого диска — это буква.
        
    - Разделитель папок — обратная черта `\` (backslash).
        
    - _Пример пути:_ `C:\Пользователи\Иван\Рабочий стол`

------------------

- **Linux (Логическое объединение):**
    
    - Есть один корень — `/` (root filesystem).
        
    - Диск C: (условно) висит в папке `/`, диск D: нужно "подмонтировать" в папку `/mnt/data`.
        
    - Флешка — это не новый диск E:, а папка `/media/usb`.
        
    - Разделитель папок — прямая черта `/` (slash).
        
    - _Пример пути:_ `/home/ivan/Рабочий_стол` (пробелы в именах заменять или экранировать).
- -----

**1. Wildcards (Подстановочные знаки)**

- `*` — любое количество символов.
    
- `?` — один любой символ.
    
- `[0-9]` — диапазон.
    
- _Внимание:_ В Linux это работает в `ls`, `rm`, `cp`. В Windows тоже, но менее гибко.
    

**2. Absolute vs Relative (Абсолютные и относительные пути)**

- **Абсолютный:** Полный путь от корня. `/home/user/file.txt` (Linux), `C:\Users\file.txt` (Win). Всегда сработает.
    
- **Относительный:** Путь от текущей папки. `../folder/file.txt`. Зависит от `pwd`.
    

**3. Hidden files (Скрытые файлы)**

- **Linux:** Любой файл, начинающийся с точки (`.`). `ls -a` чтобы увидеть.
    
- **Windows:** Файл с атрибутом `+h`. `dir /a:h` чтобы увидеть.
    

**4. Case Sensitivity (Регистр)**

- **Windows:** `FILE.TXT` = `file.txt` = `FiLe.TxT`. **Не важно**.
    
- **Linux:** `File.txt`, `file.txt`, `FILE.TXT` — это **три разных файла**. Важно!
    

**5. Extension (Расширение)**

- **Windows:** Крайне важно. Windows определяет программу по расширению (.exe, .bat, .doc).
    
- **Linux:** Расширение — это условность для человека. Исполняемость файла определяется флагом `+x`. Файл `script.sh` может быть картинкой, если у него внутри бинарные данные.
    

**6. Суперпользователь (Root vs Administrator)**

- **Windows:** UAC (User Account Control). Вы работаете с правами юзера, при необходимости кликаете "Да".
    
- **Linux:** Root — это всемогущий бог. `sudo` (Super User DO) позволяет выполнить одну команду от рута.
