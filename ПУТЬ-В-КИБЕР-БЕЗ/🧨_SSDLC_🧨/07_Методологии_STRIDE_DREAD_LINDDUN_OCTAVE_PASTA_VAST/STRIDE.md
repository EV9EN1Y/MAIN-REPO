# STRIDE – методология моделирования угроз (Microsoft)

> Отдельный файл методологии · часть 🧨_SDLC_🧨/07_Методологии

**STRIDE** – мнемоника для шести категорий угроз, разработана Praerit Garg и Loren Kohnfelder в Microsoft.

## Категории угроз

| Буква | Угроза                                        | Нарушаемое свойство                  | Пример                                     |
| ----- | --------------------------------------------- | ------------------------------------ | ------------------------------------------ |
| **S** | Spoofing (подмена)                            | Authenticity (подлинность)           | Подделка чужой сессии, подмена отправителя |
| **T** | Tampering (вмешательство)                     | Integrity (целостность)              | Изменение данных в БД, подмена пакета      |
| **R** | Repudiation (отказ)                           | Non-repudiability (неотказуемость)   | Пользователь отрицает перевод              |
| **I** | Information Disclosure (раскрытие)            | Confidentiality (конфиденциальность) | Утечка данных                              |
| **D** | Denial of Service (отказ в обслуживании)      | Availability (доступность)           | DDoS, перегрузка                           |
| **E** | Elevation of Privilege (повышение привилегий) | Authorization (авторизация)          | Пользователь стал админом                  |

## Как применять (пошагово)

1. Построить DFD системы (элементы: внешние сущности, процессы, хранилища, потоки)
2. Для КАЖДОГО элемента пройтись по всем 6 категориям STRIDE
3. Задать вопрос: "Что если S? Что если T? ..."
4. Записать угрозы в таблицу
5. Для каждой угрозы назначить контрмеру

## Контрмеры по категориям

| Категория | Контрмеры |
|-----------|-----------|
| Spoofing | Аутентификация: пароли, MFA, сертификаты, подпись JWT |
| Tampering | Целостность: хэши, HMAC, цифровые подписи, TLS |
| Repudiation | Аудит: логирование, неизменяемые логи, подписи |
| Info Disclosure | Конфиденциальность: шифрование, контроль доступа, маскирование |
| DoS | Доступность: rate limiting, лимиты, балансировка, автоскейлинг |
| Elevation | Авторизация: проверка прав, least privilege, RBAC |

## Пример применения к элементу DFD (процесс "Логин")

| # | Категория | Угроза | Контрмера |
|---|-----------|--------|-----------|
| S1 | Spoofing | Атакующий подделывает чужой JWT | Проверка подписи, короткий TTL |
| S2 | Spoofing | Брутфорс пароля | Rate limiting, блокировка, MFA |
| T1 | Tampering | Изменение тела запроса в пути | TLS, подпись запроса |
| R1 | Repudiation | Пользователь отрицает вход | Логирование входов (IP, время) |
| I1 | Info Disclosure | Ответ раскрывает, есть ли юзер | Единые сообщения об ошибках |
| D1 | DoS | Перегрузка /login | Rate limiting, WAF |
| E1 | Elevation | Подмена роли в запросе | Роль из серверной сессии, не из запроса |
