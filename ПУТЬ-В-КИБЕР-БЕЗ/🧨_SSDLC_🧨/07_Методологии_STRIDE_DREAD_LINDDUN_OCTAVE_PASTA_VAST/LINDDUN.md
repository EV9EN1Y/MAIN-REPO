# LINDDUN – моделирование угроз приватности (Privacy)

> Отдельный файл методологии · часть 🧨_SDLC_🧨/07_Методологии

**LINDDUN** – методология моделирования угроз приватности (privacy threat modeling). Дополняет STRIDE для систем, обрабатывающих персональные данные (ПДн). Актуальна для ФЗ-152 и GDPR.

## Категории угроз

| Буква | Угроза | Свойство | Пример |
|-------|--------|----------|--------|
| **L** | Linkability (связываемость) | Возможность связать данные с субъектом | По поведению понять, кто пользователь |
| **I** | Identifiability (идентифицируемость) | Возможность определить личность | По косвенным данным найти имя |
| **N** | Non-repudiation (неотказуемость) | Субъект не может отрицать действие | Негатив: нельзя "забыть" о посещении |
| **D** | Detectability (обнаруживаемость) | Можно узнать о существовании субъекта | Понять, что юзер онлайн |
| **D** | Disclosure of information (раскрытие) | Раскрытие данных третьим лицам | Продажа данных партнёрам |
| **U** | Unawareness (неосведомлённость) | Субъект не знает о сборе данных | Трекеры без согласия |
| **N** | Non-compliance (несоответствие) | Нарушение закона | Обработка без правового основания |

## Как применять

1. Построить DFD (как для STRIDE)
2. Отметить элементы, работающие с ПДн
3. Прогнать 7 категорий LINDDUN по каждому такому элементу
4. Сопоставить с требованиями ФЗ-152/GDPR
5. Назначить контрмеры приватности

## Контрмеры приватности

| Категория | Контрмеры |
|-----------|-----------|
| Linkability | Псевдонимизация, разделение хранилищ, шум |
| Identifiability | Анонимизация, агрегация, k-anonymity |
| Non-repudiation | Ограничение хранения, право на удаление |
| Detectability | Скрытие статуса, шифрование метаданных |
| Disclosure | Минимизация данных, контроль доступа |
| Unawareness | Прозрачность, информирование, consent |
| Non-compliance | Аудит, DPIA (оценка влияния на приватность) |

## Пример: соцсеть MeetWay

| # | Категория | Угроза | Контрмера |
|---|-----------|--------|-----------|
| L1 | Linkability | По геолокации постов можно вычислить адрес | Не хранить точную геолокацию, округлять |
| I1 | Identifiability | По email в профиле найти соцсети | Скрыть email по умолчанию |
| N1 | Non-repudiation | Невозможность удалить переписку полностью | Полное удаление по запросу (ст. 17 ФЗ-152) |
| D1 | Detectability | Статус "онлайн" раскрывает активность | Опция скрыть статус |
| D2 | Disclosure | Передача данных аналитике без согласия | Согласие, обезличивание |
| U1 | Unawareness | Трекеры собирают данные молча | Политика конфиденциальности, consent |
| N1 | Non-compliance | Хранение данных дольше срока | Регламент хранения, автоудаление |
