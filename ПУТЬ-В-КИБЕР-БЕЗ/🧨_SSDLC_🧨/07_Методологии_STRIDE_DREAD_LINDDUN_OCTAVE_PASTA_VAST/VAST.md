# VAST – Visual, Agile, Simple Threat Modeling

> Отдельный файл методологии · часть 🧨_SDLC_🧨/07_Методологии

**VAST** – методология моделирования угроз от компании ThreatModeler. Создана для Agile и DevOps: масштабируемая, автоматизированная, "threat modeling as code".

## Две модели VAST

### 1. Application Threat Model (модель приложения)
- Для каждого приложения/микросервиса
- Делают разработчики
- Интеграция с CI/CD
- Обновляется при каждом изменении кода

### 2. Operational Threat Model (операционная модель)
- Для инфраструктуры и окружения
- Делают Ops/DevOps
- Покрывает сеть, облако, кластеры
- Связь с архитектурой развёртывания

## Принципы VAST

| Принцип | Суть |
|---------|------|
| **Visual** | Визуальные диаграммы, понятные всем |
| **Agile** | Встроен в спринты, не отдельный процесс |
| **Simple** | Минимум бюрократии, максимум автоматизации |
| **Scalable** | Работает от 1 приложения до тысяч микросервисов |
| **Automated** | Генерация моделей из кода/инфраструктуры (IaC) |

## Как применять в DevOps

1. **Интеграция в CI/CD:** при каждом MR генерируется/обновляется модель угроз
2. **Шаблоны:** готовые шаблоны угроз для типовых компонентов (API, БД, очередь)
3. **Автоматический триггер:** изменение архитектуры (docker-compose, terraform) → новая модель
4. **Связь с задачами:** каждая угроза → задача в трекере (Jira)
5. **Метрики:** покрытие моделями, время закрытия угроз

## Пример: модель угроз микросервиса (концепт)

```yaml
# threat-model.yaml (пример "threat modeling as code")
service: payment-service
version: 1.2.0
components:
  - name: api
    type: rest-api
    threats:
      - STRIDE/Spoofing: "Нет аутентификации на /internal/*"
        severity: high
        mitigation: "mTLS между сервисами"
  - name: database
    type: postgres
    threats:
      - STRIDE/Tampering: "Нет шифрования at-rest"
        severity: medium
        mitigation: "Включить TDE/шифрование диска"
  - name: queue
    type: kafka
    threats:
      - STRIDE/Tampering: "Нет проверки целостности сообщений"
        severity: high
        mitigation: "Подпись сообщений"
```
