# Мобильная безопасность (iOS/Android)

> Полное руководство: см. остальные файлы в папке SDLC


### 18.1 Основные угрозы мобильных приложений

- Небезопасное хранение данных (кэш, plist, SharedPreferences, логи)
- Слабые криптографические реализации
- Перехват трафика (MITM) – отсутствие SSL Pinning
- Небезопасная десериализация, инъекции
- Root/Jailbreak детекция
- Обратный инжиниринг (реверс APK/IPA)
- Утечки через логи, clipboard, screenshots
- Third-party SDK (трекеры, аналитика)
> **IPA** – iOS App Store Package (формат установочного пакета iOS)

> **APK** – Android Package Kit (формат установочного пакета Android)

> **SSL** – Secure Sockets Layer (протокол защищённых сокетов (предшественник TLS))

> **MITM** – Man-in-the-Middle (атака «человек посередине»)


### 18.2 Как перехватывать трафик (тестирование)

1. **Настроить прокси:** Burp Suite / OWASP ZAP на порту 8080
2. **Установить CA-сертификат Burp** на устройство (или эмулятор)
3. **Настроить Wi-Fi proxy** устройства на IP машины:8080
4. **Android:** для приложений с user CA – включить "Trust user CAs" (API 24+), для system CA нужен root/Magisk
5. **iOS:** установить профиль сертификата (Settings → General → VPN & Device Management), включить полное доверие (Certificate Trust Settings)
6. Если трафик не идёт – приложение использует SSL Pinning
> **ZAP** – Zed Attack Proxy (инструмент OWASP для тестирования безопасности веб-приложений)

> **CA** – Certificate Authority (центр сертификации (удостоверяющий центр))

> **IP** – Internet Protocol (межсетевой протокол)

> **API** – Application Programming Interface (программный интерфейс приложения)

> **OWASP** – Open Web Application Security Project (открытый проект безопасности веб-приложений)


### 18.3 SSL Pinning и его обход

**SSL Pinning (Certificate/Public Key Pinning)** – приложение дополнительно проверяет, что сертификат сервера – именно ожидаемый (отпечаток сертификата/ключа зашит в приложение). Даже с установленным CA-сертификатом Burp перехват не работает.

**Как обойти:**
1. **Frida** – динамическая инструментация:
   ```bash
   # перехват и отключение проверки сертификатов
   frida -U -f com.app --codeshare akabe1/frida-multiple-unpinning
   ```
   - Universal Android SSL Pinning bypass (objection, frida script)
   - iOS: frida-ios-unpinning, SSL Kill Switch 2 (jailbreak)
2. **objection** – на базе Frida, одна команда:
   ```bash
   objection -g com.app explore
   # затем: android sslpinning disable
   ```
3. **Подмена сертификата** – если pin по публичному ключу, подменить ключ (сложно)
4. **Патч приложения** – декомпиляция (apktool/jadx), удаление pinning-логики, пересборка и подпись

**Инструменты:** Frida, objection, Burp Suite, MobSF, apktool, jadx, r2/radare2, Keychain-Dumper.

### 18.4 OWASP MASVS / MASTG

- **MASVS (Mobile Application Security Verification Standard)** – стандарт требований безопасности мобильных приложений (8 групп: архитектура, хранение, криптография, сеть, платформа, качество кода, устойчивость, приватность)
- **MASTG (Mobile Application Security Testing Guide)** – руководство по тестированию (как проверять каждый пункт MASVS)
> **MASTG** – Mobile Application Security Testing Guide (руководство по тестированию безопасности мобильных приложений)

> **MASVS** – Mobile Application Security Verification Standard (стандарт проверки безопасности мобильных приложений)

## 📎 Пример: обход SSL Pinning через Frida (команды и скрипт)

> Реальный рабочий подход для пентеста мобильных приложений.

### Способ 1: готовые скрипты (быстро)

```bash
# Установить frida-tools
pip install frida-tools

# Запустить приложение под Frida
frida -U -f com.example.app --codeshare akabe1/frida-multiple-unpinning

# Или через objection (проще всего)
pip install objection
objection -g com.example.app explore
# внутри objection:
#   android sslpinning disable
#   ios sslpinning disable
```

### Способ 2: свой скрипт Frida (Android)

```javascript
// unpin.js - отключение проверки сертификатов
Java.perform(function () {
    // TrustManager, который доверяет всему
    var TrustManager = Java.registerClass({
        name: 'com.example.TrustAll',
        implements: [Java.use('javax.net.ssl.X509TrustManager')],
        methods: {
            checkClientTrusted: function () {},
            checkServerTrusted: function () {},
            getAcceptedIssuers: function () { return []; }
        }
    });

    // Подмена TrustManager
    var SSLContext = Java.use('javax.net.ssl.SSLContext');
    SSLContext.init.overload(
        '[Ljavax.net.ssl.KeyManager;',
        '[Ljavax.net.ssl.TrustManager;',
        'java.security.SecureRandom'
    ).implementation = function (km, tm, sr) {
        var t = Java.array('javax.net.ssl.X509TrustManager', [TrustManager.$new()]);
        this.init(km, t, sr);
    };

    // Отключение проверки hostname (OkHttp)
    var OkHostnameVerifier = Java.use('okhttp3.internal.tls.OkHostnameVerifier');
    OkHostnameVerifier.verify.overload(
        'java.lang.String', 'javax.net.ssl.SSLSession'
    ).implementation = function () { return true; };
});
```

```bash
# Запуск
frida -U -f com.example.app -l unpin.js
```

## 📎 Пример: перехват трафика (пошагово, Burp Suite)

```bash
# 1. Запустить Burp на 0.0.0.0:8080 (Proxy -> Options -> All interfaces)

# 2. Android эмулятор: настроить proxy
adb shell settings put global http_proxy 192.168.1.10:8080

# 3. Установить CA-сертификат Burp в систему (Android 7+ нужен root/Magisk)
#    - экспортировать cert из Burp (der), конвертировать в pem
#    - скопировать в /system/etc/security/cacerts/ (нужен root)
adb push cacert.pem /data/local/tmp/
adb shell "su -c 'mount -o rw,remount /system && cp /data/local/tmp/cacert.pem /system/etc/security/cacerts/ && chmod 644 ...'"

# 4. iOS: установить профиль сертификата
#    Settings -> General -> VPN & Device Management -> Install Profile
#    Settings -> General -> About -> Certificate Trust Settings -> Enable Full Trust

# 5. Если трафик не идёт - приложение с pinning, см. обход выше (Frida/objection)
```

**Инструменты:** Burp Suite, OWASP ZAP, mitmproxy, Charles Proxy, Frida, objection, MobSF, apktool, jadx, r2.
