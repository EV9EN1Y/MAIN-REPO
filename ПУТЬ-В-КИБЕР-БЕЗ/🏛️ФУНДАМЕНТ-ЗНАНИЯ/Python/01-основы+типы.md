
# [Область видимости переменных в Python
В Python переменные могут иметь разные области видимости, что влияет на их доступность и время жизни.

1. **Глобальные переменные** - создаются в основном теле программы и доступны во всех частях программы
2. **Локальные переменные** - создаются внутри функций и доступны только внутри этих функций

Модуль `decimal` — это **встроенная библиотека Python для точных вычислений с десятичными числами**, особенно с **деньгами и финансами**.

```python
from decimal import Decimal, getcontext

# Контроль точности (знаков после запятой)
getcontext().prec = 6  # Устанавливаем общую точность 6 знаков

# Базовые операции
a = Decimal('10.5')
b = Decimal('3.2')
print(a + b)     # 13.7
print(a - b)     # 7.3
print(a * b)     # 33.6
print(a / b)     # 3.28125 (в пределах точности)

# Округление с режимами
from decimal import ROUND_HALF_UP, ROUND_DOWN
print(a.quantize(Decimal('0.00'), rounding=ROUND_HALF_UP))  # 10.50
```

Модуль math предоставляет множество полезных математических функций:

```python
import math

# Константы
pi = math.pi      # 3.141592653589793
e = math.e        # 2.718281828459045

# Тригонометрические функции (аргументы в радианах)

# Корни
sqrt_value = math.sqrt(16)    # квадратный корень, 4.0
```
