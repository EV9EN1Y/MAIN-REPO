##  Ключевые настройки для безопасного сканирования

> **Gobuster** - это инструмент для **перебора (brute-force)** скрытых каталогов, файлов, поддоменов и виртуальных хостов на веб-серверах.

Он работает по принципу "стучись во все двери": берёт список возможных имен (словарь) и проверяет, существует ли такой путь или поддомен на сервере, анализируя ответы (200, 403, 404 и т.д.). Gobuster написан на Go, поэтому он **очень быстрый** и умеет работать в многопоточном режиме

-------
**Основные режимы Gobuster:**

- **dir** — перебор каталогов и файлов на сайте (например, поиск `/admin`, `/backup.zip`).
    
- **dns** — перебор поддоменов (например, поиск `admin.example.com`, `api.example.com`).
    
- **vhost** — перебор виртуальных хостов на одном IP.
    
- **s3** — перебор Amazon S3 бакетов.

### 1. Уменьши количество потоков (`-t`)

Твои 50 потоков - это хорошо для скорости, но это **агрессивно**. Для безопасного режима используй **10–20 потоков**



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -t 15
```

**Почему:** Меньше потоков = меньше одновременных соединений = меньше нагрузка на сервер и меньше шансов, что тебя заблокирует WAF или IPS .

### 2. Добавь задержку между запросами (`--delay`)

Это самый важный флаг для безопасности. Он добавляет паузу между каждым запросом, делая сканирование незаметным.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -t 10 --delay 500ms
```
 ``--delay 500ms` — задержка 500 миллисекунд (полсекунды) между запросами.`
    
- Для совсем "нежных" систем ставь `1s` (одна секунда).
    

**Почему:** Это имитирует поведение обычного пользователя и не даёт WAF/IDS повода заблокировать твой IP за флуд .

### 3. Используй случайную задержку (`--random-delay`)

Вместо фиксированной задержки можно использовать случайную, чтобы сканирование было ещё менее предсказуемым.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -t 10 --random-delay 100ms-1000ms
```

**Почему:** Варьирующаяся задержка ещё сильнее сбивает с толку автоматические системы защиты, которые ищут закономерности.

### 4. Ограничь общее время (`--timeout`)

Установи таймаут на каждый запрос, чтобы `gobuster` не висел на медленно отвечающих ресурсах.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt --timeout 10s
```
**Почему:** Это предотвращает зависание и снижает общую нагрузку на сервер, так как `gobuster` не будет долго ждать ответа от проблемных путей.

### 5. Не сканируй слишком глубоко

Ограничь глубину рекурсивного сканирования, если используешь флаг `-r`.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -r -L 2
```
- `-L 2` — сканировать только 2 уровня вложенности (например, `/admin/`, но не `/admin/users/`).
    

**Почему:** Глубокая рекурсия может создать лавину запросов, которую сервер не выдержит .

### 6. Игнорируй определённые коды статуса

Зачастую ответы 403 (Forbidden) или 404 (Not Found) можно сразу игнорировать, чтобы не захламлять вывод и не тратить время.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -b 404,403
```
**Почему:** Ты не будешь перебирать тысячи страниц с ошибками, а сосредоточишься только на тех, что могут быть интересны.

### 7. Используй прокси (если нужно)

Если ты работаешь через корпоративный прокси или хочешь скрыть свой IP, укажи прокси.



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt --proxy http://127.0.0.1:8080
```
**Почему:** Весь трафик пойдёт через Burp Suite или другой прокси, где ты сможешь его контролировать и анализировать.

## 🏁 Полный пример безопасной команды

Вот как будет выглядеть твой `gobuster`, который быстро, но безопасно прощупает сайт:



```c
gobuster dir -u https://example.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,log,backup -t 15 --delay 500ms --timeout 10s -b 404,403 -o results.txt
```

**Что делает эта команда:**

- `-t 15` — умеренное количество потоков (не перегружает сервер)
    
- `--delay 500ms` — полусекундная пауза между запросами
    
- `--timeout 10s` — таймаут на каждый запрос
    
- `-b 404,403` — игнорирует бесполезные статусы, чтобы результат был чище
    
- `-o results.txt` — сохраняет результат в файл, чтобы не потерять
