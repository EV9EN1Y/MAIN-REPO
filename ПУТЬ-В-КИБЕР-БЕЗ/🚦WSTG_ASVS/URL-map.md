установка  urlmap
```c

cd ~/Downloads
# Скачай архив
curl -L -o urlmap.tar.gz https://github.com/aoshimash/urlmap/releases/latest/download/urlmap-darwin-arm64.tar.gz

# Распаковка чееек
tar -xzvf urlmap.tar.gz

# 1.  права на выполнение
chmod +x urlmap-darwin-arm64
# 2. Переместить в системную папку (чтобы можно было запускать из любого места)
sudo mv urlmap-darwin-arm64 /usr/local/bin/urlmap
# 3. проверочка
urlmap --help
```

запуск 
```c
# Базовое сканирование
urlmap https://example.com

# С ограничением глубины и ускорением
urlmap https://example.com --depth 3 --concurrent 20

----------
ЭТИЧНЫЙ ЗАПУСК


urlmap https://example.com --depth 2 --concurrent 1 --rate-limit 1

- Ограничит глубину обхода до 2 уровней.
    
- Будет отправлять по одному запросу за раз.
    
- Не превысит скорость в 1 запрос в секунду.

```

настройки скорости и глубины
```c
### Глубина сканирования
- `--depth 1` — проверит только главную страницу и ссылки на ней.
    
- `--depth 2` — перейдет по ссылкам с главной, а затем по ссылкам с этих страниц.
    
- `--depth 5` (по умолчанию) — базовый уровень для средних сайтов.
    
- `--depth 0` — бесконечная глубина (обойдет весь сайт)
  
  
  --------------
  
  
  ### Ускорение сканирования
- `--concurrent 5` (по умолчанию) — безопасный режим.
    
- `--concurrent 20` — ускоряет процесс, но может быть заметен для сервера.
    
- `--concurrent 50` — агрессивный режим, может вызвать блокировку
  
  
```


**Полезные опции:**

- `--depth 3` — ограничить глубину обхода (сколько уровней вложенности пройти) [](https://github.com/aoshimash/urlmap).
    
- `--concurrent 20` — использовать больше одновременных потоков для ускорения [](https://github.com/aoshimash/urlmap).
    
- `--verbose` — видеть больше деталей процесса [](https://github.com/aoshimash/urlmap).
    
- `--rate-limit 5` — ограничить скорость запросов (важно, чтобы не перегрузить сайт)

Для большинства обычных сайтов `urlmap` отработает отлично. Однако у него есть важное ограничение: он анализирует статический HTML-код и **не обрабатывает JavaScript** 
Если сайт написан на React, Vue или Angular (так называемые SPA - Single Page Applications), он может найти не все ссылки, потому что многие из них генерируются динамически уже после загрузки страницы [](https://github.com/aoshimash/urlmap/issues/46). Сейчас в разработке находится версия с поддержкой рендеринга JavaScript, но на данный момент она еще не выпущена
