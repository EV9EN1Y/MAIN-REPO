### 7000 проверок

очень заметный!

**Nikto** - это инструмент оценки веб-серверов, который проверяет их на наличие опасных файлов, устаревшего ПО, ошибок конфигурации и потенциально опасных настроек . Он прогоняет цели по огромной базе, которая насчитывает около 7000 проверок, выискивая «низко висящие фрукты» - то, что можно найти быстро и без глубокого анализа 

**Ключевая особенность:** Nikto **очень шумный** . Он создан для быстрого сканирования, а не для скрытности. Его активность гарантированно попадёт в логи веб-сервера и может быть замечена системами защиты (IDS/IPS) . Он не эксплуатирует уязвимости, а только сообщает об их наличии 

---

##  Основные возможности

- Проверка на наличие опасных и дефолтных файлов и CGI-скриптов 
    
- Поиск устаревших версий ПО на сервере 
    
- Проверка на ошибки конфигурации (небезопасные HTTP-методы, отсутствие заголовков безопасности) 
    
- Определение установленного ПО по заголовкам, иконкам и файлам 
    
- Поддержка SSL/TLS и сканирование нестандартных портов 
    
- Работа через HTTP-прокси 
    
- Авторизация на хосте (Basic и NTLM) 
    
- Сохранение отчётов в разных форматах: TXT, XML, HTML, CSV, NBE
    
- Возможность тонкой настройки сканирования через пааметры

##  Базовые команды и флаги

  

|Флаг / Опция|Что делает|Пример|
|---|---|---|
|`-h <host>`|Указывает цель: IP-адрес или домен|`nikto -h https://example.com`|
|`-p <port>`|Указывает порт (по умолчанию 80)|`nikto -h example.com -p 443`|
|`-ssl`|Принудительно использует SSL/TLS|`nikto -h example.com -ssl`|
|`-Tuning <options>`|Выбирает конкретные категории тестов|`-Tuning 2,3`|
|`-o <file>`|Сохраняет результаты в файл|`-o result.txt`|
|`-Format <type>`|Формат отчёта: txt, xml, html, csv, nbe|`-Format html`|
|`-useragent <str>`|Устанавливает свой User-Agent (для маскировки)|`-useragent "Mozilla/5.0"`|
|`-vhost <host>`|Указывает виртуальный хост для заголовка `Host`|`-vhost example.com`|
|`-useproxy`|Использует прокси (из конфига или указанного)|`-useproxy -proxyhost 127.0.0.1 -proxyport 8080`|
|`-id <id>`|HTTP Basic-авторизация (username:password)|`-id "admin:password"`|
|`-timeout <sec>`|Таймаут ожидания ответа от сервера|`-timeout 10`|
|`-maxtime <time>`|Максимальное время сканирования|`-maxtime 1h`|
|`-Pause <sec>`|Задержка между тестами (для снижения нагрузки)|`-Pause 1`|
|`-update`|Обновляет локальную базу уязвимостей|`perl nikto.pl -update`|



## 🔧 Настройка тестов (`-Tuning`)

Этот флаг позволяет отсечь лишнее и сфокусироваться на конкретных типах уязвимостей 

|Символ|Тип теста|
|---|---|
|`0`|File Upload (загрузка файлов)|
|`1`|Interesting File / Seen in logs (интересные файлы)|
|`2`|Misconfiguration / Default File (ошибки конфигурации)|
|`3`|Information Disclosure (раскрытие информации)|
|`4`|Injection (XSS, SQL, Command)|
|`5`|Remote File Retrieval|
|`6`|Denial of Service|
|`7`|Remote File Inclusion|
|`8`|Authentication Bypass|
|`9`|Software Identification|
|`a`|Все тесты (по умолчанию)|

**Пример:** `nikto -h https://example.com -Tuning 2,3,9` - проверит только ошибки конфигурации, утечки информации и идентифицирует ПО

##  Ключевые настройки для безопасного сканирования

Nikto - сканер «грубой силы», но его можно сделать чуть аккуратнее

### 1. Используй задержку между тестами (`-Pause`)

Замедляет сканирование, снижая нагрузку на сервер и делая его менее заметным 


```c
nikto -h https://example.com -Pause 1

это 1 сек между запросами

родной случайной задержки нет, но можно сделать так

export http_proxy='socks5://127.0.0.1:9050' && export https_proxy='socks5://127.0.0.1:9050' && nikto -h https://example.com -ssl -Delay 1 -max-time 3600

или обернуть через кастом скрипт на питоне
```

### 2. Ограничь время сканирования (`-maxtime`)

Не даёт сканеру зависнуть на нестабильном сервере 



```c
nikto -h https://example.com -maxtime 1h
```

### 3. Подмени User-Agent (`-useragent`)

Стандартный User-Agent Nikto легко детектится. Маскируйся под обычный браузер 


```c
nikto -h https://example.com -useragent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
```

### 4. Используй прокси (`-useproxy`)

Для скрытности или работы через корпоративный прокси


```c
nikto -h https://example.com -useproxy -proxyhost 127.0.0.1 -proxyport 8080
```

### 5. Настрой конкретные тесты (`-Tuning`)

Не гоняй «все подряд», если не нужно. Это экономит время и уменьшает шум 

```c
nikto -h https://example.com -Tuning 2,3
```

##  Полный пример безопасной команды

Вот как может выглядеть твой `nikto`, который выполнит целенаправленное и аккуратное сканирование:



```c
nikto -h https://example.com -Tuning 2,3,9 -useragent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" -Pause 0.5 -maxtime 30m -o scan_results.html -Format html
```

**Что делает эта команда:**

- `-h https://example.com` - цель
- `-Tuning 2,3,9` - проверяет ошибки конфигурации, утечки и определяет ПО
- `-useragent "..."` - маскируется под Firefox
- `-Pause 0.5` - делает паузу 0.5 секунды между тестами
- `-maxtime 30m` - ограничивает время сканирования 30 минутами
- `-o scan_results.html -Format html` - сохраняет отчёт в HTML-файл

##  будет в отчёте



- **Версия сервера:** Устаревшая или нет
   
- **Опасные HTTP-методы:** `TRACE` (для кражи cookie), `PUT` (для загрузки файлов)
   
- **Открытые конфигурационные файлы:** `/phpinfo.php`, `/admin/`, `.git`, `robots.txt`
   
- **Отсутствующие заголовки безопасности:** `X-Frame-Options`, `X-Content-Type-Options`
